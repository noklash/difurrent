02 Philosophy

Technology,
built with understanding.

We prefer evidence over assumptions.

We look closely at how systems actually behave so we can solve real problems rather than symptoms. We build before we speculate. We measure before we optimize.

We investigate the systems behind the software, from infrastructure and networks to applications and their dependencies. We don't treat complex systems as black boxes.

The goal is simple: technology that works, can be understood, and can be improved.

Systems / Linux

ProcWatch

A self-contained Linux process monitoring tool that reconstructs process information directly from the kernel's /proc filesystem.

ProcWatch explores what actually happens underneath familiar process monitoring tools.

Instead of invoking ps, top, or another external process utility, the program reads Linux's /proc interface directly.

The project covers process enumeration, metadata, CPU utilisation, memory usage, filtering, sorting, process hierarchy, file descriptors, and memory mappings.
