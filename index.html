ProcWatch

A self-contained Linux process-monitoring tool written in C.

ProcWatch reconstructs process information directly from Linux's /proc filesystem, the kernel interface through which process information is exposed to userspace.

The project explores process enumeration, process metadata, CPU utilisation, memory usage, process hierarchy, file descriptors, and memory mappings without relying on external process-listing utilities.

The purpose was to understand where process-monitoring data actually comes from and how the operating system exposes it, rather than treating the output of existing tools as a black box.
